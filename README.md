# 《溫柔生長讀書誌》｜在權力不對等處立足：心智自立與邊界守護

一份以十本經典原著為基石的深度閱讀誌，專注於職場權力、人際界線、反覆自責、過度付出、完美主義與自我價值等核心生命課題。

讀者可以從日常具體情境出發，理解各書提供的深刻視角，再選擇適合自身節奏的生活實踐方式。本站以成熟、溫潤且具建設性的陪伴口吻，協助讀者在真實處境中找回內在力量與主動權。

## ✨ 網站核心功能與閱讀動線

1. **首頁十大專書導讀盤**：
   * 包含真實書封展示、四維向度雷達、核心痛點剖析與伴讀心法。
   * 收錄 10 則首頁編輯閱讀摘記（附一鍵複製摘記與跳轉功能）。
2. **十本專書深度專頁（`book-*.html`）**：
   * **痛點導讀**：針對特定人際與職場困境切入。
   * **八則編輯閱讀摘記**：各書專屬的精選觀點與指引。
   * **三種常見情境與應對選擇**：深入職場、社交、家庭的具體對話解析。
   * **三項日常實踐練習**：提供日常可嘗試的沉澱行動方案。
   * **EPUB 下載專區**：標示檔案大小、支援閱讀器清單，並整合 Readify AI 官方連結。
3. **十二題閱讀起點探索（Interactive Assessment）**：
   * 勾選當前處境，即時運算四維向度分數（R 反芻自責、P 職場權力、B 人際界線、O 過度努力），指引最適起點。
4. **六種高壓情境回應練習（In-Situ Playbook）**：
   * 聚焦任務超載、情緒施壓、重複請託、會議質疑、負面評語與深夜反芻，提供成熟應對話術。
5. **五本支援工具書互補矩陣（Tactical Toolkit）**：
   * 涵蓋《關鍵對話》、《突破盲點的談判思維》、《難度跨越》、《非暴力溝通》與《被討厭的勇氣》。
6. **電子書資源下載中心與 Readify AI 官方整合**：
   * 官方推薦使用 **Readify AI**（[https://readifyai.com/zh](https://readifyai.com/zh)）享受自然語音朗讀與問答輔助。
   * 完整相容 Apple Books、微信讀書、Kobo、Kindle 等本機電子書載具。

## 🛠️ 工程架構與維護規範

* **雙首頁同位元對齊鐵律**：
  `index.html` 與 `preview-bullet-journal-main.html` 必須始終保持 SHA256 100% 同位元一致。所有首頁修改必須同步更新兩檔。
* **行動端文字排版防護**：
  `assets/book-margin-companions.css` 中注入 `.showcase-chip > span:first-child` 與 `.bujo-companion-reminder .reminder-tag` 之 `flex: 0 0 auto; white-space: nowrap;`，防止在 320px/375px 小螢幕下標籤（如「作者：」、「出版：」）被拆字垂直折行。
* **頁尾版面約束**：
  頁尾版權資訊必須收斂在 `.container` 內部，避免脫離版心造成靠左出界。
* **章節抽屜導航對稱性**：
  全站 11 個導航項目皆配置對應語義圖示（如 `💬 現場溝通練習`）。
* **安全標頭與雲端部署**：
  專案根目錄備有 `_headers`，透過 `cloudflare-deploy-ops/scripts/deploy.py` 直傳 Cloudflare Pages 邊緣節點，嚴格套用 CSP、HSTS、noindex 爬蟲防護等安全標頭。

詳細架構歷程與治理規範請參閱 [PROJECT_GOVERNANCE.md](PROJECT_GOVERNANCE.md)。
