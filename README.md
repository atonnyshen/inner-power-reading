## 🧠 受困者深度畫像：退讓與內耗的共謀機制

1. **迷走神經凍結（Freeze & Fawn，當下的退讓機制）**：  
   身處權力傾斜場合時，人體背側迷走神經會瞬間觸發「凍結」或「討好」反應。前額葉皮質血液被抽離，只能機械性道歉、退讓或吞下不合理要求。這是童年面對強大威脅時習得的存活防衛本能，絕非意志軟弱。
2. **反芻風暴與大腦失控小對話（Rumination Loop，事後的內部凌遲）**：  
   離開現場後，大腦默認網絡（DMN）過度活躍，試圖用「邏輯理性」平復情緒衝擊，反墮入每分鐘數千字的反芻黑洞。對外部不公的憤怒，全數轉化為對自己的嚴厲審判。
3. **公正世界假說與弱勢執念（Just-World Fallacy，認知盲區）**：  
   弱勢者默默相信「只要我做得夠好、夠誠懇，就會被公正對待」。但現實組織從不按童話運行；刻意迴避權力競爭，只會將規則制定權拱手讓給索取者。
4. **假性孤兒與過度努力模式（Parental Conditioning，童年印記）**：  
   童年成長於情緒不成熟家庭的孩子，過早扮演「情緒照顧者」，將自我價值與「順從、表現完美」死死綁定。這份恐懼在成年後原封不動地移植到了職場權威面前。

- **階梯 III：當下防禦（In-Situ Boundaries）**

- **階梯 IV：源頭解咒（Root Liberation）**

  核心目標：回溯童年假性孤兒印記，卸下完美主義防衛，完成真正的課題分離與內在自立。
