# 溫柔生長讀書誌｜從十本書找到適合自己的閱讀起點

這是一份以十本原著為基礎的個人閱讀指南，整理職場權力、人際界線、反覆自責、過度付出、完美主義與自我價值等主題。

讀者可以從具體情境開始，理解各書提供的觀點，再選擇適合自己生活條件的閱讀與練習方式。本站保留作者觀點與編輯延伸之間的區別，不將情境建議寫成所有人都必須遵守的處方。

## 網站提供的功能

- 首頁十本書導讀與閱讀摘記。
- 十本獨立長頁，各有原書概述、三種情境、八則編輯閱讀摘記及三項可調整的日常練習。
- 十二題「閱讀起點探索」，依所選情境提供四個主題面向與建議書目。**分數只是閱讀導航工具，並非心理診斷或經驗證的心理量表。**
- 六組高壓情境回應示例。示例由編輯撰寫，不能視為原作者逐字引文。
- 繁體與簡體中文切換、行動裝置排版、章節導覽，以及 EPUB 閱讀資源連結。

**摘記與來源：** 首頁十則與專頁八十則均標示為「編輯閱讀摘記」，是來源支持的轉述或編輯應用；需要確認作者原句時，請閱讀相應的原著版本。五本補充閱讀書目不納入本專案的原著逐項核證範圍。

## 技術與版本

本站以 HTML、CSS 與 JavaScript 製作。首頁為 `index.html`，`preview-bullet-journal-main.html` 為同步預覽；十本專頁位於根目錄的 `book-*.html`。圖片、書封與樣式存放於 `assets/`、`img/` 及 `covers/`。

本機候選版已完成指定 Chromium 視口、章節跳轉、書封燈箱、摘記複製及繁簡切換測試。**這些測試不代表已使用真實 iPhone Safari、Android 或螢幕閱讀器完成全部驗收。**

書目原著的 EPUB 檔案在本次文字編輯中保持不變。最新本機內容收據及測試資料另存於專案外的驗收工作目錄，並非網站對外展示的內容。
