像貓一樣守護邊界：鬆弛、自洽與不討好

在不對等的權力關係中，我們總被社會化要求「聽話、配合、懂事」。但一隻貓從不因他人的期待而感到羞恥。牠在陽光下安然舒展，在受侵犯時果斷確立邊界。這是一份將貓咪神經自洽轉化為手帳心理防禦的實驗設計頁面。

● SECTION 01 // FELINE EMBODIMENT PROTOCOLS

貓咪核心三階自處法則：從身心反應到內在防衛

[ RULE : 01 / POSTURE ]

身體鬆弛，勝過百句辯解

貓在安全時全身如流水般放鬆；但在邊界被觸碰時，牠不會先道歉，而是平靜而清晰地拉開距離。面對職場強勢者的情緒傾倒，先讓雙肩下沉、呼吸放緩，拒絕身體層面的本能凍結。

FIG. REF-P1
[ RULE : 02 / REJECTION ]

不帶敵意的溫和拒絕

當貓不想被摸時，牠只是輕巧地偏過頭走開，既不恐慌也不帶著罪惡感。學習「停、看、應」的界線守護：明確陳述自己的限制，不為他人的不滿而承擔過剩的自責。

FIG. REF-P2
[ RULE : 03 / FOCUS ]

收斂注意力，停止精神反芻

離開衝突現場後，貓會立刻坐下來專心舔毛。牠不會在夜深人靜時反覆審問自己「剛剛我是不是做錯了」。將抽離的精力收回到手帳與手頭實體事物，斬斷大腦失控的自責重播。

● SECTION 03 // DAILY HABIT CHECKER

今日手帳打卡：像貓一樣生活的 5 個微練習

01. 戒斷習慣性道歉： 在今天發出的工作訊息或郵件中，將開頭的「不好意思 / 抱歉」改為「感謝你的耐心等待 / 感謝你的確認」。
02. 守護 15 分鐘的發呆界線： 午餐後給自己一段完全不看社群動態、不回覆瑣碎訊息的時間，像貓在窗台曬太陽一樣全然放空。
03. 不接突如其來的非本職差事： 當他人試圖推卸責任時，溫和直視對方回覆：「這項工作目前不在我的排程內，建議依照常規流程提報。」
04. 睡前終止精神反芻： 當大腦開始播放「今天開會如果換個說法就好了」時，用手掌輕拍胸口三次，默念：「今天的考驗已經結束，我已做到當時的最好。」
05. 在手帳寫下一件肯定自己的事： 無論多微小（如準時下班、喝足了溫水），給自己蓋上一枚心靈的及格戳章。
